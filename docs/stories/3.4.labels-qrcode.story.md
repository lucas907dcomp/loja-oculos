## Story

**As a** store owner,
**I want** to generate and print price labels with QR codes for my product variants,
**so that** I can physically label my products in the store and provide a digital link to each variant's future e-commerce page (spec.md Sections 5.4, FR-10, AC-10.1 – AC-10.3).

## Acceptance Criteria

1. **No schema migration required** — `LabelService` queries existing tables:
   - `ProductVariant` (sku, frameColor, lensColor, salePrice, productId) for variant data and price
   - `Product` (name, brand, isArchived) — only non-archived products included
   - No new tables or columns needed
   - (FR-10)

2. `src/features/labels/label.contract.ts` — exports 1 interface:
   - `LabelData`: `{ variantId: string; productName: string; brand: string; sku: string; frameColor: string; lensColor: string; salePrice: number; qrUrl: string; qrCodeDataUrl: string }`
     - `qrUrl`: composed as `(process.env.LABEL_QR_BASE_URL ?? '') + '/p/' + variant.sku` — works without env var (relative URL)
     - `qrCodeDataUrl`: base64 PNG data URL from `qrcode.toDataURL(qrUrl)` — render as `<img src={...} />`
     - `salePrice`: plain `number` (converted from Prisma `Decimal` via `Number()`)
   - Barrel-exported from `src/features/labels/index.ts` alongside `LabelService`
   - (FR-10, AC-10.1, AC-10.2)

3. `src/features/labels/services/label.service.ts` — `LabelService` class (static pattern):
   - `getVariantLabels(variantIds: string[]): Promise<LabelData[]>` — queries `productVariant.findMany` where `id in variantIds` and `product.isArchived = false`; includes `product`; converts `salePrice` with `Number()`; calls `qrcode.toDataURL(qrUrl)` for each variant; returns empty array if `variantIds` is empty
   - `getProductLabels(productId: string): Promise<LabelData[]>` — queries all non-archived variants of the product (`productVariant.findMany` where `productId` and `product.isArchived = false`); delegates QR generation to `getVariantLabels` logic (or calls shared helper)
   - Install: `npm install qrcode && npm install -D @types/qrcode`
   - (FR-10, AC-10.1, AC-10.2)

4. `src/features/labels/actions.ts` — Server Action (`'use server'`):
   - `getLabelsByProductAction(productId: string): Promise<{ success: true; data: LabelData[] } | { success: false; error: string }>`
   - `getLabelsByVariantsAction(variantIds: string[]): Promise<{ success: true; data: LabelData[] } | { success: false; error: string }>`
   - (FR-10)

5. `app/(backoffice)/etiquetas/page.tsx` — Server Component (RSC):
   - Accepts `searchParams: { productId?: string }` — if present, fetches labels via `LabelService.getProductLabels(productId)` in a try/catch; on error renders `<p className="text-destructive">Erro ao gerar etiquetas.</p>`
   - Always fetches product list for the selector via direct Prisma call or `ProductsService.findAll()` (non-archived only)
   - Renders `<EtiquetasClient products={products} labels={labels} selectedProductId={searchParams.productId} />`
   - No `'use client'` directive
   - (FR-10, AC-10.1, AC-10.2, AC-10.3)

6. `app/(backoffice)/etiquetas/etiquetas-client.tsx` — Client Component (`'use client'`):
   - **Product selector**: `<select>` or shadcn `<Select>` listing all products; onChange navigates to `?productId={id}` via `useRouter().push()`
   - **Label grid**: when labels are present, renders each `LabelData` as a label card:
     - Product name + brand (bold)
     - Frame color / Lens color (muted text)
     - SKU (monospace text)
     - Price formatted as BRL (e.g., "R$ 199,90")
     - QR Code: `<img src={label.qrCodeDataUrl} alt={label.sku} className="h-16 w-16" />`
   - **Quantity per variant**: each label card has a numeric input (1–10, default 1); labels repeat in print based on quantity
   - **Print button**: `<Button onClick={() => window.print()}>Imprimir</Button>` — triggers browser print dialog
   - **@media print styles**: `<style>{...}</style>` rendered inside the component to hide sidebar (`aside`) and show only `#labels-print-area`; label grid uses `display: grid` normally, `display: block` for print
   - **Empty state**: when no product is selected → `"Selecione um produto para gerar etiquetas"`
   - No forms with POST, no mutations, no `useTransition`
   - (FR-10, AC-10.1, AC-10.2, AC-10.3)

7. `src/components/layout/sidebar.tsx` — Modified (add Etiquetas nav item):

   - (FR-10)

8. `.env.local.example` — Modified (add label env var):

### No Schema Migration (Critical Note)

[Source: prisma/schema.prisma — current state]

`LabelService` is a pure read service. All required data is already in the database:
- `ProductVariant.sku`, `ProductVariant.frameColor`, `ProductVariant.lensColor`, `ProductVariant.salePrice` (Decimal)
- `ProductVariant.productId` → `Product.name`, `Product.brand`, `Product.isArchived`

**Do NOT create a migration for this story.** No new tables or columns are needed.

### QR Code Library — `qrcode`

[Source: spec.md Section 5.4 — `src/features/labels/services/label.service.ts`]

Use the `qrcode` npm package (most maintained, works in Node.js + browser):

```bash
npm install qrcode
npm install -D @types/qrcode
```

Generate base64 PNG data URL (use `<img src={...} />` — no `dangerouslySetInnerHTML`):

```typescript
import QRCode from 'qrcode'

const qrCodeDataUrl = await QRCode.toDataURL(qrUrl)
// → 'data:image/png;base64,iVBORw0KGg...'
```

**CRITICAL:** `toDataURL()` is async — always `await`. Batch all QR generations with `Promise.all`:

```typescript
const results = await Promise.all(
  variants.map(async (v) => {
    const qrUrl = (process.env.LABEL_QR_BASE_URL ?? '') + '/p/' + v.sku
    const qrCodeDataUrl = await QRCode.toDataURL(qrUrl)
    return { ...labelFields, qrUrl, qrCodeDataUrl }
  })
)
```

```typescript
  if (variantIds.length === 0) return []   // ← early return, no DB call
  const variants = await prisma.productVariant.findMany(...)
  ...
}
```

### Static Service Pattern Reference

[Source: src/features/analytics/services/analytics.service.ts — Story 3.3; src/features/customers/services/customer.service.ts — Story 3.1]

Follow the same static class pattern:
- No DI, no constructor
- All methods `static async`
- Import `prisma` from `@/lib/prisma`

```typescript
// src/features/labels/services/label.service.ts
import { prisma } from '@/lib/prisma'
import QRCode from 'qrcode'
import type { LabelData } from '../label.contract'

export class LabelService {
  static async getVariantLabels(variantIds: string[]): Promise<LabelData[]> { ... }
  static async getProductLabels(productId: string): Promise<LabelData[]> { ... }
}
```

### Page RSC Pattern

[Source: src/app/(backoffice)/dashboard/page.tsx — Story 3.3]

Same RSC try/catch pattern — assign data outside try, return component outside try:

```typescript
// app/(backoffice)/etiquetas/page.tsx
export default async function EtiquetasPage({ searchParams }: { searchParams: Promise<{ productId?: string }> }) {
  const { productId } = await searchParams
  const products = await ProductsService.findAll()   // or direct Prisma

  let labels: LabelData[] = []
  if (productId) {
    try {
      labels = await LabelService.getProductLabels(productId)
    } catch {
      return <p className="text-destructive font-medium">Erro ao gerar etiquetas.</p>
    }
  }

  return <EtiquetasClient products={products} labels={labels} selectedProductId={productId} />
}
```

### Quantity-per-label Repeat Pattern

[Source: AC-10.3 — "Impressão em lote"]

When printing multiple copies of the same label, render the label `quantity` times in the DOM:

```tsx
{labels.flatMap((label) =>
  Array.from({ length: quantities[label.variantId] ?? 1 }, (_, i) => (
    <LabelCard key={`${label.variantId}-${i}`} label={label} />
  ))
)}
```

State: `const [quantities, setQuantities] = useState<Record<string, number>>({})`.
