## Story

**As a** store owner (cashier),
**I want** a functional Point-of-Sale screen where I can browse active product variants, add them to a cart, specify payment method(s), and confirm the sale with a button click,
**so that** I can register a sale in ≤ 3 clicks with < 2-second response, backed by the atomic `SalesService.createSale()` from Story 2.1 (spec.md Section 3.2, FR-3, NFR-1, NFR-2).

## Acceptance Criteria

1. `src/features/sales/stores/cart.store.ts` exports `useCartStore` (Zustand `create<CartStore>`) and selector `selectTotal`:
   - **State:** `items: CartItem[]`, `paymentBreakdown: PaymentBreakdown` (from `sales.contract.ts`); initially `items = []`, `paymentBreakdown = {}`
   - **`CartItem` type (local to store):** `{ variantId: string; sku: string; productName: string; frameColor: string; lensColor: string; salePrice: Decimal; quantity: number }` — `salePrice` is a `Decimal` instance (never a plain `number`)
   - **Actions (five):**
     - `addItem(item: Omit<CartItem, 'quantity'>, quantity?: number)` — if `variantId` already in cart, increments its `quantity` by `quantity` (default 1); otherwise appends new `CartItem` with given `quantity`
     - `removeItem(variantId: string)` — removes matching item; no-op if not found
     - `updateQuantity(variantId: string, quantity: number)` — sets quantity; if `quantity < 1`, removes the item entirely
     - `setPaymentBreakdown(breakdown: PaymentBreakdown)` — replaces `paymentBreakdown` in state
     - `clearCart()` — resets `items = []` and `paymentBreakdown = {}`
   - **`selectTotal(state: CartStore): Decimal`** — computes `Σ (salePrice × quantity)` for each item with Decimal.js (zero floating-point exposure); exported as standalone selector used as `useCartStore(selectTotal)` (FR-4, NFR-3)
   - `useCartStore` and `selectTotal` barrel-exported from `src/features/sales/index.ts`

2. `src/app/(backoffice)/pdv/page.tsx` — Server Component (replaces placeholder):
   - Calls `ProductsService.findAll({ includeArchived: false })` to pre-fetch active products with variants and inventory
   - Renders `<PdvClient products={products} />` passing the result as prop
   - No `'use client'` directive on this file

3. `src/app/(backoffice)/pdv/pdv-client.tsx` — Client Component (new file):
   - `'use client'` directive at top
   - Receives `products: ProductWithVariants[]` prop
   - **Layout:** two-panel, side-by-side — product list (left) and cart + payment (right)
   - **Left panel — Product List:**
     - Lists active variants grouped by product: product name, SKU, `frameColor / lensColor`, `salePrice` formatted as `R$ X,XX`, stock badge from `inventory?.quantity ?? 0`
     - Each variant has an "Adicionar" button; click calls `addItem({ variantId, sku, productName, frameColor, lensColor, salePrice }, 1)` on the cart store
     - Variants with `inventory.quantity === 0` display a "Sem estoque" badge and their "Adicionar" button is disabled (UI guard; EC-1 in `SalesService` remains the authoritative server-side guard)
   - **Right panel — Cart:**
     - Table of cart `items`: productName, SKU, unit price, quantity controls (– / qty / +), subtotal, remove button
     - Quantity `–` calls `updateQuantity(variantId, quantity - 1)` (removes item when reaching 0); `+` calls `updateQuantity(variantId, quantity + 1)`
     - Shows cart `total` via `useCartStore(selectTotal)` formatted as `R$ X,XX`
     - Empty cart state: message "Nenhum item no carrinho" (no crash)
   - **Right panel — Payment:**
     - Numeric inputs for Pix, Cartão Crédito, Cartão Débito, Dinheiro (all optional; routed to `setPaymentBreakdown`)
     - When cart total changes, the Pix input auto-fills to `Number(total.toFixed(2))` unless the user has manually edited any payment field (auto-fill enables the ≤3 click path: add variant → Pix pre-filled → confirm)
     - Live validation feedback: green "Pagamento OK" when `Σ paymentBreakdown === total` (Decimal equality); red "Diferença: R$ X,XX" otherwise
     - "Confirmar Venda" button disabled when cart is empty or payment does not cover total
   - **Confirm flow:**
     - Clicking "Confirmar Venda" calls `createSaleAction({ items: items.map(i => ({ variantId: i.variantId, quantity: i.quantity })), paymentBreakdown })` from `src/features/sales/actions.ts`
     - On `success: true`: show success message including `saleId`, call `clearCart()`
     - On `success: false`: show `error` message from action (FR-3, NFR-1, NFR-2)

   - `updateQuantity` to 0 — removes item from cart

### Zustand v5 Pattern (package.json: `"zustand": "^5.0.4"`)
[Source: spec.md#section-3-1 — "Zustand 4.5+ para carrinho do PDV"; actual installed: v5]

```typescript
// src/features/sales/stores/cart.store.ts
import { create } from 'zustand'
import Decimal from 'decimal.js'
import type { PaymentBreakdown } from '../sales.contract'

export interface CartItem {
  variantId: string
  sku: string
  productName: string
  frameColor: string
  lensColor: string
  salePrice: Decimal   // ← Decimal instance, never number
  quantity: number
}

interface CartStore {
  items: CartItem[]
  paymentBreakdown: PaymentBreakdown
  addItem: (item: Omit<CartItem, 'quantity'>, quantity?: number) => void
  removeItem: (variantId: string) => void
  updateQuantity: (variantId: string, quantity: number) => void
  setPaymentBreakdown: (breakdown: PaymentBreakdown) => void
  clearCart: () => void
}

export const useCartStore = create<CartStore>((set) => ({
  items: [],
  paymentBreakdown: {},
  addItem: (item, quantity = 1) =>
    set((state) => {
      const existing = state.items.find((i) => i.variantId === item.variantId)
      if (existing) {
        return {
          items: state.items.map((i) =>
            i.variantId === item.variantId ? { ...i, quantity: i.quantity + quantity } : i,
          ),
        }
      }
      return { items: [...state.items, { ...item, quantity }] }
    }),
  removeItem: (variantId) =>
    set((state) => ({ items: state.items.filter((i) => i.variantId !== variantId) })),
  updateQuantity: (variantId, quantity) =>
    set((state) => {
      if (quantity < 1) return { items: state.items.filter((i) => i.variantId !== variantId) }
      return {
        items: state.items.map((i) => (i.variantId === variantId ? { ...i, quantity } : i)),
      }
    }),
  setPaymentBreakdown: (breakdown) => set({ paymentBreakdown: breakdown }),
  clearCart: () => set({ items: [], paymentBreakdown: {} }),
}))

// Standalone selector — use as: useCartStore(selectTotal)
export function selectTotal(state: CartStore): Decimal {
  return state.items.reduce(
    (sum, item) => sum.plus(item.salePrice.mul(item.quantity)),
    new Decimal(0),
  )
}
```

### Payment Breakdown Auto-fill + Validation Pattern
[Source: FR-3 AC-3.3; NFR-1 — ≤3 clicks]

```typescript
// In PdvClient — track if user manually edited payment
const [userEditedPayment, setUserEditedPayment] = useState(false)

// Auto-fill Pix when total changes and user hasn't manually edited
useEffect(() => {
  if (!userEditedPayment) {
    setPaymentBreakdown({ pix: Number(total.toFixed(2)) })
  }
}, [total, userEditedPayment])

// Payment sum validation (Decimal equality — not ===)
const paymentSum = new Decimal(paymentBreakdown.pix ?? 0)
  .plus(paymentBreakdown.cardCredit ?? 0)
  .plus(paymentBreakdown.cardDebit ?? 0)
  .plus(paymentBreakdown.cash ?? 0)
const isPaymentValid = paymentSum.equals(total)
```

### salePrice Type Bridging (ProductsService → CartStore)
[Source: products.contract.ts — `VariantWithInventory.salePrice: Decimal` (Prisma Decimal type)]

Prisma returns `salePrice` as a `Decimal` object from `@db.Decimal(10,2)`. The `addItem` call can pass it directly:

```typescript
// In PdvClient:
addItem({
  variantId: variant.id,
  sku: variant.sku,
  productName: product.name,
  frameColor: variant.frameColor,
  lensColor: variant.lensColor,
  salePrice: variant.salePrice,  // ← already Decimal from Prisma
}, 1)
```

However, `CartItem.salePrice` must be a `Decimal` instance (from `decimal.js`), not the Prisma Decimal type. Both implement the same interface; a `new Decimal(variant.salePrice.toString())` conversion is safe if needed.
