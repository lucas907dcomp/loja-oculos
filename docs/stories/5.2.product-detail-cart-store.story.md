## Story

**As a** cliente da Vitrine visitando a página de detalhe de um produto,
**I want** visualizar a galeria de imagens da variante selecionada, escolher minha variante (cor de armação, cor de lente, UV, polarizado), ver o preço e status de estoque individuais, e adicionar ao carrinho,
**so that** posso escolher exatamente o óculos que quero antes de entrar em contato (spec.md FR-14, CON-6, CON-7, CON-8, Epic 5 — Headless E-commerce Vitrine).

   - Zustand store com `persist` middleware (localStorage, key `'otica-cart'`)
   - Interface pública:
     ```typescript
     interface CartItem {
       variantId: string
       sku: string
       productName: string
       variantLabel: string    // ex: "Preto / Cinza"
       price: string           // Decimal string, ex: "199.90"
       imageUrl: string | null
       quantity: number
     }
     interface CartState {
       items: CartItem[]
       addItem: (item: Omit<CartItem, 'quantity'>) => void
       removeItem: (variantId: string) => void
       updateQuantity: (variantId: string, quantity: number) => void
       clearCart: () => void
       totalItems: () => number
       totalPrice: () => string  // "R$ 399,80"
     }
     ```

   - `updateQuantity(variantId, qty)`: se `qty <= 0`, chama `removeItem`; caso contrário, atualiza `quantity`

### Cart Store — Zustand Persist

```typescript
// src/store/cart.ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'
import Decimal from 'decimal.js'

// CartItem e CartState types conforme AC 5
export const useCartStore = create<CartState>()(
  persist(
    (set, get) => ({
      items: [],
      addItem: (item) => set((state) => {
        const existing = state.items.find((i) => i.variantId === item.variantId)
        if (existing) {
          return { items: state.items.map((i) => i.variantId === item.variantId ? { ...i, quantity: i.quantity + 1 } : i) }
        }
        return { items: [...state.items, { ...item, quantity: 1 }] }
      }),
      removeItem: (variantId) => set((state) => ({ items: state.items.filter((i) => i.variantId !== variantId) })),
      updateQuantity: (variantId, quantity) => {
        if (quantity <= 0) { get().removeItem(variantId); return }
        set((state) => ({ items: state.items.map((i) => i.variantId === variantId ? { ...i, quantity } : i) }))
      },
      clearCart: () => set({ items: [] }),
      totalItems: () => get().items.reduce((sum, i) => sum + i.quantity, 0),
      totalPrice: () => {
        const total = get().items.reduce(
          (sum, i) => sum.plus(new Decimal(i.price).times(i.quantity)),
          new Decimal(0)
        )
        return parseFloat(total.toString()).toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' })
      },
    }),
    { name: 'otica-cart' }
  )
)
```
