## Story

**As a** cliente da Vitrine que adicionou produtos ao carrinho,
**I want** ver a contagem de itens no ícone do header e abrir um drawer lateral para revisar meu carrinho, ajustar quantidades e remover produtos,
**so that** posso conferir minha seleção antes de prosseguir para o checkout (spec.md FR-15, CON-8, Epic 5 — Headless E-commerce Vitrine).

## Acceptance Criteria

1. **`CartHeader`** — `src/features/storefront/components/cart-header.tsx` (`'use client'`):
   - Gerencia estado local `isOpen: boolean` com `useState(false)`
   - Renderiza um `<button>` com o ícone SVG de carrinho (mesmo ícone já presente em `layout.tsx`)
   - Badge ao lado do ícone mostrando `useCartStore((s) => s.totalItems())`:
     - Oculto (não renderizado) quando `totalItems() === 0`
     - Exibe a contagem como número; se > 99 exibe `"99+"`
   - Clique no botão: `setIsOpen(true)`
   - Renderiza `<CartDrawer open={isOpen} onClose={() => setIsOpen(false)} />`
   - (FR-15, CON-8)

2. **`CartDrawer`** — `src/features/storefront/components/cart-drawer.tsx` (`'use client'`):
   - Props: `{ open: boolean; onClose: () => void }`
   - Estrutura: overlay `fixed inset-0` semi-transparente (clicável para fechar) + painel deslizante da direita
   - Transição CSS: `transition-transform duration-300`; painel com `translate-x-full` quando `!open` e `translate-x-0` quando `open`; overlay com `pointer-events-none opacity-0` quando `!open`
   - Botão `×` no cabeçalho do drawer chama `onClose()`; clique no overlay chama `onClose()`
   - **Estado vazio** quando `items.length === 0`:
     - Mensagem "Seu carrinho está vazio"
     - Link "Continuar comprando" → `/loja/produtos`
   - **Lista de itens** (`items` de `useCartStore`), para cada item:
     - Imagem: `next/image` 64×64 quando `imageUrl != null`; placeholder cinza quando `null`
     - Textos: `productName` (bold), `variantLabel` (texto menor, cinza), preço unitário formatado
     - Controles de quantidade: botão `−` → `updateQuantity(variantId, quantity - 1)`, display da quantidade, botão `+` → `updateQuantity(variantId, quantity + 1)`
     - Botão remover `×` (ou ícone lixeira) → `removeItem(variantId)`
   - **Rodapé fixo** do drawer:
     - Total: `"Total: {totalPrice()}"` em destaque
     - Link `<Link href="/loja/checkout">` com texto "Ir para Checkout" (estilo botão preto), preparando rota para Story 5.4
   - (FR-15, CON-8)

3. **Atualização do layout** — `src/app/(storefront)/loja/layout.tsx`:
   - Substituir o bloco `<Link href="/loja/carrinho">` com seu conteúdo interno (ícone SVG + span `"0"`) por `<CartHeader />`
   - Importar `CartHeader` de `@/features/storefront/components/cart-header`
   - O layout permanece Server Component; `CartHeader` é o client island
   - (FR-15, FR-19)

4. **Testes unitários** — `src/features/storefront/__tests__/cart-ui.test.tsx`:
   - Mock: `vi.mock('@/store/cart', () => ({ useCartStore: vi.fn() }))`
   - Helper local: `mockStore(overrides)` que retorna estado padrão mesclado com overrides e configura `vi.mocked(useCartStore).mockImplementation((sel) => sel ? sel(state) : state)`
   - **CartHeader**:
     - Renderiza badge com contagem quando `totalItems() > 0`
     - Não renderiza badge quando `totalItems() === 0`
     - Badge exibe `"99+"` quando `totalItems() > 99`
   - **CartDrawer** (com `open={true}`):
     - Renderiza estado vazio ("Seu carrinho está vazio") quando `items = []`
     - Renderiza nome do produto quando `items` tem 1 item
     - Botão `removeItem` chama `removeItem(variantId)`
     - Botão `−` chama `updateQuantity(variantId, quantity - 1)`
     - Botão `onClose` (fechar `×`) chama o callback `onClose`
   - (FR-15)

5. **Typecheck + lint** — `npx tsc --noEmit` e `npm run lint` passam com zero erros; `ECOMMERCE_API_KEY` ausente em todos os arquivos `'use client'`
   - (CON-7, CON-8)

### Client Island Pattern no App Router

```
layout.tsx (Server Component)
  └── <CartHeader /> (Client Component — `'use client'`)
        ├── useState(isOpen)
        ├── <button> com badge (totalItems do Zustand)
        └── <CartDrawer open={isOpen} onClose={...} />
```

**Regra:** O arquivo `layout.tsx` NÃO deve receber `'use client'`. Apenas `CartHeader` e `CartDrawer` têm `'use client'`. Filhos Server Components de `layout.tsx` (`{children}`) não são afetados.

### CartHeader — Pattern de Badge

```tsx
'use client'
import { useState } from 'react'
import { useCartStore } from '@/store/cart'
import { CartDrawer } from './cart-drawer'

export function CartHeader() {
  const [isOpen, setIsOpen] = useState(false)
  const count = useCartStore((s) => s.totalItems())

  return (
    <>
      <button
        onClick={() => setIsOpen(true)}
        aria-label="Abrir carrinho"
        className="relative flex items-center gap-1 text-gray-600 hover:text-gray-900"
      >
        {/* SVG do carrinho (mesmo que estava em layout.tsx) */}
        {count > 0 && (
          <span className="flex h-5 w-5 items-center justify-center rounded-full bg-black text-xs text-white">
            {count > 99 ? '99+' : count}
          </span>
        )}
      </button>
      <CartDrawer open={isOpen} onClose={() => setIsOpen(false)} />
    </>
  )
}
```
