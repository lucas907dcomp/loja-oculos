## Story

**As a** cliente da loja visitando a Vitrine online,
**I want** visualizar o catálogo de produtos em um grid responsivo com filtro por marca e indicação de disponibilidade em estoque,
**so that** posso encontrar o óculos que procuro, ver o preço e saber se está disponível antes de entrar em contato (spec.md FR-13, FR-19, CON-6, CON-7, Epic 5 — Headless E-commerce Vitrine).

## Acceptance Criteria

1. **Route group `(storefront)` com layout público** — `src/app/(storefront)/loja/layout.tsx` criado:
   - Header: logotipo/nome da loja à esquerda; ícone de carrinho (link placeholder para futura Story 5.3) com badge `0` à direita
   - Footer: linha com nome da loja, "Contato" (e-mail configurável via env `STOREFRONT_EMAIL`) e ano atual
   - Sem autenticação — rota pública; `src/middleware.ts` existente não afeta `/loja/*` (matcher é `/api/v1/:path*`)
   - (FR-13, FR-19, CON-6)

2. **BFF API module** — `src/lib/storefront/api.ts` criado com funções server-side:
   - `getProducts(brand?: string): Promise<ExportProduct[]>` — chama `fetch('/api/v1/products?brand=X')` com header `X-Api-Key: process.env.ECOMMERCE_API_KEY` e `next: { revalidate: 300 }` (ISR 5 min)
   - `getInventory(): Promise<InventoryEntry[]>` — chama `fetch('/api/v1/inventory')` com mesmo header e cache
   - Variável `NEXT_PUBLIC_APP_URL` (ou `process.env.NEXT_PUBLIC_VERCEL_URL`) usada para construir a URL base absoluta (necessário em Server Components do Next.js 16)
   - Ambas as funções retornam array vazio (`[]`) em caso de erro (não propagam exceção — loja fica vazia, não quebra)
   - `ECOMMERCE_API_KEY` lida server-side; nunca em código `'use client'`
   - (CON-6, CON-7)

3. **Homepage da Vitrine** — `src/app/(storefront)/loja/page.tsx`:
   - Server Component que chama `getProducts()` e `getInventory()` em paralelo com `Promise.all`
   - Renderiza `<ProductGrid>` com todos os produtos (sem filtro de marca na homepage)
   - Título "Nosso Catálogo" + link "Ver todos os produtos" → `/loja/produtos`
   - (FR-13)

4. **Página de listagem** — `src/app/(storefront)/loja/produtos/page.tsx`:
   - Server Component com `searchParams: { brand?: string }` para receber o filtro
   - Chama `getProducts(searchParams.brand)` e `getInventory()` em paralelo
   - Renderiza `<BrandFilter brands={brands} activeBrand={searchParams.brand}>` acima do grid
   - Renderiza `<ProductGrid products={...} inventory={...}>`
   - Título "Produtos" + contagem de resultados ex: "24 produtos"
   - (FR-13, FR-17-parcial, FR-19)

5. **Componente `ProductCard`** — `src/features/storefront/components/product-card.tsx`:
   - Imagem principal: `variants[0].images[0]` com `next/image`; fallback para placeholder quando `images` está vazio
   - Nome do produto (`product.name`) e marca (`product.brand`)
   - Menor preço das variantes: `Math.min(...variants.map(v => parseFloat(v.price)))` formatado como `R$ 199,90`
   - Contagem de variantes disponíveis: `N variantes` (baseado em variantes com `stock > 0` via cruzamento com inventory)
   - Badge de estoque: "Em estoque" (verde) se pelo menos 1 variante tem `stock > 0`; "Esgotado" (cinza) se todas têm `stock === 0`
   - Link para `/loja/produtos/{product.id}` (detalhe — implementado em Story 5.2)
   - (FR-13, CON-6)

6. **Componente `ProductGrid`** — `src/features/storefront/components/product-grid.tsx`:
   - Grid Tailwind: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6`
   - Props: `products: ExportProduct[]`, `inventory: InventoryEntry[]`
   - Estado vazio: mensagem "Nenhum produto encontrado" quando `products.length === 0`
   - Skeleton de carregamento: 6 cards placeholder (usado via `<Suspense fallback={<ProductGrid.Skeleton />}>` se necessário)
   - (FR-13, FR-19)

7. **Componente `BrandFilter`** — `src/features/storefront/components/brand-filter.tsx`:
   - Lista de marcas únicas extraídas dos produtos recebidos
   - Botão "Todos" (ativo quando `activeBrand` é undefined) + um botão por marca
   - Ao clicar, navega para `/loja/produtos?brand={marca}` via `<Link>` (Client Component com `'use client'`)
   - Marca ativa com estilo diferenciado (ex: `bg-black text-white`)
   - (FR-13)

8. **Cruzamento de estoque** — helper puro `src/lib/storefront/inventory.ts`:
   - `getVariantStock(variantId: string, inventory: InventoryEntry[]): number` — retorna `quantity` ou `0`
   - `isProductInStock(product: ExportProduct, inventory: InventoryEntry[]): boolean` — `true` se qualquer variante tem `stock > 0`
   - Funções puras, sem efeitos colaterais, testáveis de forma isolada
   - (FR-13)

9. **Testes unitários** — `src/features/storefront/__tests__/storefront-api.test.ts` e `inventory.test.ts`:

   - `getInventory()`: idem
   - `getVariantStock()`: variante existente → retorna quantity; variante ausente → retorna 0
   - `isProductInStock()`: produto com ao menos 1 variante em estoque → true; produto sem estoque → false
   - (FR-13, CON-7)

10. **Typecheck + lint** — `npx tsc --noEmit` e `npm run lint` passam com zero erros; nenhuma env `NEXT_PUBLIC_ECOMMERCE_API_KEY` usada (chave nunca exposta ao client).

### BFF Pattern (CON-6, CON-7)

```typescript
// src/lib/storefront/api.ts  (server-only — sem 'use client')
import type { ExportProduct } from '@/features/export/export.contract'
import type { InventoryEntry } from '@/app/api/v1/inventory/route'  // ou definir inline

const BASE_URL = process.env.NEXT_PUBLIC_APP_URL
  ?? (process.env.VERCEL_URL ? `https://${process.env.VERCEL_URL}` : 'http://localhost:3000')

async function apiFetch<T>(path: string): Promise<T> {
  try {
    const res = await fetch(`${BASE_URL}/api/v1${path}`, {
      headers: { 'X-Api-Key': process.env.ECOMMERCE_API_KEY ?? '' },
      next: { revalidate: 300 },
    })
    if (!res.ok) return [] as unknown as T
    return res.json()
  } catch {
    return [] as unknown as T
  }
}

export const getProducts = (brand?: string): Promise<ExportProduct[]> =>
  apiFetch(`/products${brand ? `?brand=${encodeURIComponent(brand)}` : ''}`)

export const getInventory = () =>
  apiFetch<InventoryEntry[]>('/inventory')
```

> `ECOMMERCE_API_KEY` lida server-side; nunca em `NEXT_PUBLIC_*` [CON-7].

### Inventory Cross-Reference

```typescript
// src/lib/storefront/inventory.ts
export const getVariantStock = (variantId: string, inv: InventoryEntry[]) =>
  inv.find(e => e.variantId === variantId)?.quantity ?? 0

export const isProductInStock = (product: ExportProduct, inv: InventoryEntry[]) =>
  product.variants.some(v => getVariantStock(v.id, inv) > 0)
```
