## Story

**As a** store owner,
**I want** to view real-time stock levels for every product variant, receive low-stock alerts, review the full movement history, and make manual stock adjustments (purchases and corrections),
**so that** I always know what's on the shelf, get warned before running out, and have an auditable trail of every stock change (spec.md Section 1.1, FR-2 rationale).

No monetary fields in this contract — inventory is quantity-only (FR-2).

2. `src/features/inventory/services/inventory.service.ts` exports `InventoryService` with the following methods — all reads via Prisma, writes via `prisma.$transaction()` where data integrity matters:
   - `getInventoryList()` — returns all `ProductVariant`s (non-archived products only) joined with `Inventory` and parent `Product`; ordered by product name then SKU; maps to `InventoryListItem[]`
   - `getVariantHistory(variantId: string)` — returns `InventoryTransaction[]` for the variant ordered by `createdAt DESC`; returns empty array if no transactions exist
   - `getLowStockAlerts()` — returns `LowStockAlert[]` for variants where `inventory.quantity <= inventory.minStockAlert`
   - `getZeroStockVariants()` — returns `InventoryListItem[]` where `inventory.quantity === 0`
   - `adjustStock(variantId: string, dto: AdjustStockDTO)` — validates `dto.quantity >= 1`; for `PURCHASE` computes `delta = +dto.quantity`; for `ADJUSTMENT` computes `delta = dto.sign === '-' ? -dto.quantity : +dto.quantity`; validates resulting quantity would not go below 0 (throws `Error('Estoque insuficiente')` if it would); inside `prisma.$transaction()`: atomically increments/decrements `Inventory.quantity` and creates an `InventoryTransaction` record with correct `type`, `quantityDelta` and optional `note`
   - `updateMinStockAlert(variantId: string, value: number)` — validates `value >= 0` (throws on negative); updates `Inventory.minStockAlert`

model Inventory {
  id            String                 @id @default(cuid())
  quantity      Int                    @default(0)
  minStockAlert Int                    @default(3)
  variantId     String                 @unique
  variant       ProductVariant         @relation(fields: [variantId], references: [id])
  transactions  InventoryTransaction[]
  createdAt     DateTime               @default(now())

model InventoryTransaction {
  id            String    @id @default(cuid())
  type          TxType    // SALE | PURCHASE | RETURN | EXCHANGE | ADJUSTMENT
  quantityDelta Int       // signed: positive = stock in, negative = stock out
  note          String?
  inventoryId   String
  inventory     Inventory @relation(fields: [inventoryId], references: [id])
  createdAt     DateTime  @default(now())
  // NOTE: append-only — no UPDATE or DELETE operations (FR-2 AC-2.3 audit trail)
}

enum TxType {
  SALE        // created by SalesService (Epic 2) — read-only in this story
  PURCHASE    // created by InventoryService.adjustStock (this story)
  RETURN      // created by SalesService (Epic 2)
  EXCHANGE    // created by SalesService (Epic 2)
  ADJUSTMENT  // manual correction via backoffice (this story)

### adjustStock Logic
[Source: spec.md#section-3-3 — prisma.$transaction pattern; FR-2 AC-2.1, EC-1]

```typescript
// src/features/inventory/services/inventory.service.ts
async adjustStock(variantId: string, dto: AdjustStockDTO) {
  const inventory = await prisma.inventory.findUniqueOrThrow({ where: { variantId } })

  // Compute signed delta
  const delta = dto.type === 'PURCHASE'
    ? dto.quantity
    : dto.sign === '-' ? -dto.quantity : dto.quantity  // ADJUSTMENT

  const newQuantity = inventory.quantity + delta
  if (newQuantity < 0) throw new Error('Estoque insuficiente')  // EC-1 guard

  return prisma.$transaction(async (tx) => {
    await tx.inventory.update({
      where: { id: inventory.id },
      data: { quantity: newQuantity }
    })
    await tx.inventoryTransaction.create({
      data: {
        inventoryId: inventory.id,
        type: dto.type,
        quantityDelta: delta,
        note: dto.note ?? null
      }
    })
  })
}
```

**Critical:** `quantity >= 0` check must happen **before** opening the transaction. Do not rely on the DB to reject it.

### getInventoryList Query Pattern
[Source: spec.md#section-5-2; FR-2 AC-2.1, AC-2.4]

```typescript
async getInventoryList(): Promise<InventoryListItem[]> {
  const variants = await prisma.productVariant.findMany({
    where: { product: { isArchived: false } },  // exclude archived products
    include: {
      product: { select: { name: true } },
      inventory: true
    },
    orderBy: [
      { product: { name: 'asc' } },
      { sku: 'asc' }
    ]
  })
  return variants.map(v => {
    const qty = v.inventory?.quantity ?? 0
    const min = v.inventory?.minStockAlert ?? 0
    const status = qty === 0 ? 'Zerado' : qty <= min ? 'Alerta' : 'Normal'
    return {
      variantId: v.id,
      inventoryId: v.inventory!.id,
      sku: v.sku,
      productName: v.product.name,
      frameColor: v.frameColor,
      lensColor: v.lensColor,
      quantity: qty,
      minStockAlert: min,
      status
    }
  })
}
```
