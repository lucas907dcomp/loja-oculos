## Story

**As a** store owner,
**I want** to process a product exchange against a completed sale — returning the original items to stock and decrementing the replacement items — in a single atomic operation,
**so that** inventory stays accurate and the sales history reflects the exchange (spec.md Section 3.3, FR-9 AC-9.1, AC-9.3).

## Acceptance Criteria

1. **No new schema migration required** — exchange uses existing tables:
   - `Sale` (status field: `COMPLETED → RETURNED`)
   - `SaleItem` (read-only — original items used as return list)
   - `Inventory` (increment returned, decrement new)
   - `InventoryTransaction` (types: `RETURN`, `EXCHANGE` — already in enum)
   - No new tables or columns needed.
   - (FR-9)

2. `SalesService.processExchange(saleId: string, newItems: CreateSaleItemDTO[]): Promise<SaleWithItems>` — atomic exchange operation added to `src/features/sales/services/sales.service.ts`:
   - Validates `newItems.length >= 1`; throws `Error('Lista de itens da troca não pode estar vazia')`
   - Fetches original sale via `getSaleById(saleId)`; throws `Error('Venda não encontrada')` if not found
   - Validates original sale `status === 'COMPLETED'`; throws `Error('Venda já foi devolvida ou trocada')` if not
   - Pre-transaction stock check: for each new item, fetches `Inventory`; throws `Error('Estoque insuficiente para {productName} — {sku}')` if `inventory.quantity < item.quantity`

     a. Updates `Sale.status` to `'RETURNED'`
     b. For each original sale item: increments `Inventory.quantity` by `item.quantity`; creates `InventoryTransaction(RETURN, +item.quantity)`
     c. For each new item: decrements `Inventory.quantity` by `item.quantity`; creates `InventoryTransaction(EXCHANGE, -item.quantity)`
   - Returns the updated `SaleWithItems` (re-fetches with full includes after transaction)
   - No `CashFlowEntry` created (MVP simplification: assumes equal-value exchange; financial delta deferred)

   - On error: returns `{ success: false; error: string }`

### processExchange — Implementation Reference

[Source: spec.md Section 3.3 — `prisma.$transaction()` pattern; FR-9 AC-9.1]

Follow the exact same atomic pattern as `processReturn()` but add the new-items-decrement step:

```typescript
static async processExchange(
  saleId: string,
  newItems: CreateSaleItemDTO[],
): Promise<SaleWithItems> {
  if (newItems.length === 0) throw new Error('Lista de itens da troca não pode estar vazia')

  const sale = await SalesService.getSaleById(saleId)
  if (sale.status !== 'COMPLETED') throw new Error('Venda já foi devolvida ou trocada')

  // Pre-transaction stock check for new items (same as createSale EC-1 pattern)
  const newVariantData = await Promise.all(
    newItems.map((item) =>
      prisma.productVariant.findUniqueOrThrow({
        where: { id: item.variantId },
        include: { product: { select: { name: true } }, inventory: true },
      }),
    ),
  )
  for (let i = 0; i < newItems.length; i++) {
    const inv = newVariantData[i].inventory
    if (!inv || inv.quantity < newItems[i].quantity) {
      throw new Error(
        `Estoque insuficiente para ${newVariantData[i].product.name} — ${newVariantData[i].sku}`,
      )
    }
  }

  return prisma.$transaction(async (tx) => {
    // a. Mark original sale as RETURNED
    await tx.sale.update({ where: { id: saleId }, data: { status: 'RETURNED' } })

    // b. Restore inventory for each original item (RETURN)
    for (const item of sale.items) {
      const inv = await tx.inventory.findUniqueOrThrow({ where: { variantId: item.variantId } })
      await tx.inventory.update({
        where: { id: inv.id },
        data: { quantity: { increment: item.quantity } },
      })
      await tx.inventoryTransaction.create({
        data: { inventoryId: inv.id, type: 'RETURN', quantityDelta: item.quantity, note: null },
      })
    }

    // c. Decrement inventory for each new item (EXCHANGE)
    for (let i = 0; i < newItems.length; i++) {
      const item = newItems[i]
      const inv = newVariantData[i].inventory!
      await tx.inventory.update({
        where: { id: inv.id },
        data: { quantity: { decrement: item.quantity } },
      })
      await tx.inventoryTransaction.create({
        data: { inventoryId: inv.id, type: 'EXCHANGE', quantityDelta: -item.quantity, note: null },
      })
    }

    // NO CashFlowEntry — MVP assumption: equal-value exchange

    return tx.sale.findUniqueOrThrow({
      where: { id: saleId },
      include: {
        items: {
          include: { variant: { include: { product: { select: { name: true } } } } },
        },
        customer: true,
        cashFlowEntry: true,
      },
    }) as Promise<SaleWithItems>
  })
}
```
