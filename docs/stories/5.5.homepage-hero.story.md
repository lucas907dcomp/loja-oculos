## Story

**As a** visitante da Vitrine,
**I want** ver uma homepage com hero section atraente e uma seleção de produtos em destaque,
**so that** tenho uma primeira impressão profissional da loja e navego diretamente para os produtos de maior interesse (spec.md FR-18, FR-19, Epic 5 — Headless E-commerce Vitrine).

## Acceptance Criteria

1. **`HeroSection`** — `src/features/storefront/components/hero-section.tsx` (Server Component):
   - Exibe banner hero com: headline principal (ex: "Óculos de Sol com Estilo"), subtítulo (ex: "Encontre o modelo perfeito para você"), botão CTA "Ver Coleção Completa" → `<Link href="/loja/produtos">`
   - Design responsivo mobile-first: padding adequado, texto legível em telas pequenas
   - Background escuro (ex: `bg-gray-900`) com texto branco; pode usar gradiente
   - (FR-18, FR-19)

2. **Homepage atualizada** — `src/app/(storefront)/loja/page.tsx` (Server Component):
   - Renderiza `<HeroSection />` no topo
   - Abaixo do hero: seção "Produtos em Destaque" com os primeiros **6 produtos** do catálogo (`products.slice(0, 6)`)
   - Usa `<ProductGrid>` existente para renderizar os 6 produtos
   - Link "Ver todos os produtos →" abaixo do grid apontando para `/loja/produtos`
   - Remove o layout atual (catálogo completo sem hero) e substitui pela estrutura hero + destaques
   - (FR-18, FR-19)

3. **Testes unitários** — `src/features/storefront/__tests__/homepage.test.tsx`:
   - Mock de `@/lib/storefront/api` para `getProducts` e `getInventory`
   - Mock de `@/features/storefront/components/product-grid` e `hero-section`
   - Casos:
     - Homepage renderiza `<HeroSection>` (ou texto do headline)
     - Homepage renderiza link "Ver Coleção Completa" com `href="/loja/produtos"`
     - Homepage renderiza seção "Produtos em Destaque"
     - Homepage renderiza link "Ver todos os produtos →" com `href="/loja/produtos"`
     - Se catálogo tem 10 produtos, apenas 6 são passados para o grid
   - (FR-18)

4. **Typecheck + lint** — `npx tsc --noEmit` e `npm run lint` passam com zero erros
   - (CON-7)

### Homepage Atualizada — Estrutura

```tsx
// src/app/(storefront)/loja/page.tsx
import Link from 'next/link'
import { getProducts, getInventory } from '@/lib/storefront/api'
import { ProductGrid } from '@/features/storefront/components/product-grid'
import { HeroSection } from '@/features/storefront/components/hero-section'

export default async function StorefrontHomePage() {
  const [products, inventory] = await Promise.all([getProducts(), getInventory()])
  const featured = products.slice(0, 6)

  return (
    <>
      <HeroSection />
      <div className="mx-auto max-w-7xl px-4 py-10">
        <div className="mb-6 flex items-baseline justify-between">
          <h2 className="text-xl font-bold text-gray-900">Produtos em Destaque</h2>
          <Link href="/loja/produtos" className="text-sm text-gray-600 hover:underline">
            Ver todos os produtos →
          </Link>
        </div>
        <ProductGrid products={featured} inventory={inventory} />
      </div>
    </>
  )
}
```

### Testes — Abordagem para Server Components

`page.tsx` é um Server Component async. Para testar com Vitest + RTL:
- Mock de `@/lib/storefront/api` retornando arrays síncronos
- Mock de `@/features/storefront/components/product-grid` e `hero-section` como stubs
- Usar `renderAsync` pattern ou testar componentes filhos individualmente
