## Story

**As a** store owner,
**I want** to see the sales velocity per variant, days until stockout forecast, dead stock alerts, and a KPI summary (revenue, average ticket, average margin) in an executive dashboard,
**so that** I can make proactive restocking decisions, identify slow-moving inventory (capital at risk), and understand overall store performance at a glance (spec.md Sections 3.2, 5.4, FR-8, FR-11, AC-8.1 – AC-8.3, AC-11.1 – AC-11.4).

## Acceptance Criteria

1. **No schema migration required** — `AnalyticsService` queries existing tables:
   - `SaleItem` (quantity, unitPrice, unitCost, variantId, saleId, createdAt) for velocity and margin
   - `Sale` (totalAmount, status, createdAt) joined via `SaleItem.sale` — only `COMPLETED` sales count
   - `Inventory` (quantity, variantId) for current stock levels
   - `ProductVariant` (sku, frameColor, lensColor, costPrice, salePrice, productId) for margin and variant labels
   - `Product` (name, brand, isArchived) — only non-archived products are included
   - (FR-8, FR-11)

2. `src/features/analytics/analytics.contract.ts` — exports 6 interfaces:
   - `SalesVelocityRecord`: `{ variantId: string; productName: string; brand: string; sku: string; frameColor: string; lensColor: string; unitsSold: number; weeksCovered: number; unitsPerWeek: number }`
   - `StockoutForecast`: extends `SalesVelocityRecord` with `{ currentStock: number; daysUntilStockout: number | null; isCritical: boolean }`
   - `DeadStockRecord`: `{ variantId: string; productName: string; brand: string; sku: string; frameColor: string; lensColor: string; currentStock: number }`
   - `TopMarginRecord`: `{ variantId: string; productName: string; brand: string; sku: string; frameColor: string; lensColor: string; salePrice: number; costPrice: number; marginPercent: number }`
   - `TopTurnoverRecord`: `{ variantId: string; productName: string; brand: string; sku: string; frameColor: string; lensColor: string; unitsPerWeek: number; unitsSold: number }`
   - `PeriodSummary`: `{ totalRevenue: number; totalSales: number; averageTicket: number; averageMarginPercent: number; from: string; to: string }`
   - All types barrel-exported from `src/features/analytics/index.ts` alongside `AnalyticsService`
   - (FR-8, FR-11)

3. `src/features/analytics/services/analytics.service.ts` — `AnalyticsService` class (static pattern):
   - `getSalesVelocity(lookbackDays?: number): Promise<SalesVelocityRecord[]>` — default `lookbackDays = 28`; queries `SaleItem.findMany` where `sale.status = COMPLETED` and `createdAt >= since`; aggregates `quantity` per `variantId` in TypeScript; `unitsPerWeek = unitsSold / (lookbackDays / 7)`; includes `variant.product` for name/brand; returns empty array if no sales
   - `getCriticalStockouts(threshold?: number, lookbackDays?: number): Promise<StockoutForecast[]>` — default `threshold = 7`, `lookbackDays = 28`; calls `getSalesVelocity()` internally; queries all active variant inventories via `inventory.findMany`; computes `daysUntilStockout = (quantity / unitsPerWeek) * 7` (null if `unitsPerWeek = 0`); filters to `isCritical = daysUntilStockout !== null && daysUntilStockout < threshold`; sorted by `daysUntilStockout ASC`
   - `getDeadStock(daysSinceLastSale?: number): Promise<DeadStockRecord[]>` — default `daysSinceLastSale = 60`; queries `ProductVariant.findMany` where `product.isArchived = false`; includes `saleItems` filtered to COMPLETED sales within the last `daysSinceLastSale` days; returns variants where `saleItems.length === 0` (no recent completed sales)
   - `getTopByMargin(limit?: number): Promise<TopMarginRecord[]>` — default `limit = 10`; queries all non-archived variants; computes `marginPercent = (salePrice - costPrice) / salePrice * 100` (returns 0 if `salePrice = 0`); sorts DESC; returns top `limit`
   - `getTopByTurnover(lookbackDays?: number, limit?: number): Promise<TopTurnoverRecord[]>` — default `lookbackDays = 28`, `limit = 10`; calls `getSalesVelocity()` internally; sorts by `unitsPerWeek DESC`; returns top `limit`
   - `getPeriodSummary(from: Date, to: Date): Promise<PeriodSummary>` — queries `Sale.findMany` where `status = COMPLETED` and `createdAt >= from` and `createdAt <= to`; `totalRevenue = SUM(sale.totalAmount)`; `totalSales = COUNT`; `averageTicket = totalRevenue / totalSales` (0 if no sales); `averageMarginPercent = mean of (unitPrice - unitCost) / unitPrice * 100` across all `SaleItems` in the period (0 if no items)
   - (FR-8 AC-8.1, AC-8.2, AC-8.3, FR-11 AC-11.1, AC-11.2, AC-11.3, AC-11.4)

4. `src/features/analytics/actions.ts` — Server Action (`'use server'`):
   - `getAnalyticsDashboardAction()` — calls all 5 `AnalyticsService` methods in parallel (`Promise.all`); returns `{ success: true; data: DashboardData }` or `{ success: false; error: string }`
   - `DashboardData` interface in `actions.ts`: `{ summary: PeriodSummary; topByMargin: TopMarginRecord[]; topByTurnover: TopTurnoverRecord[]; criticalStockouts: StockoutForecast[]; deadStock: DeadStockRecord[] }`
   - Default period for `getPeriodSummary`: last 30 days (`from = new Date(Date.now() - 30 * 24 * 60 * 60 * 1000)`, `to = new Date()`)

### Decimal Conversion — CRITICAL

[Source: spec.md Section 3.1 — "Rationale financeiro crítico"; prisma/schema.prisma — `Decimal @db.Decimal(10,2)`]

Prisma 5 returns `Decimal` objects (from the `decimal.js` library) for `@db.Decimal` fields. These are NOT JavaScript numbers. Arithmetic on them requires `.toNumber()` or `Number()`:

```typescript
// WRONG — returns NaN or Decimal object, not a JS number
const margin = (v.salePrice - v.costPrice) / v.salePrice * 100

// CORRECT
const sp = Number(v.salePrice)
const cp = Number(v.costPrice)
const margin = sp > 0 ? ((sp - cp) / sp) * 100 : 0
```

The `AnalyticsService` returns plain TypeScript `number` in its contract types — the conversion must happen inside the service, not in the UI.

### SalesVelocity — Aggregation Pattern

[Source: spec.md Section 6.1 — `AnalyticsService.getSalesVelocity()` test; FR-8 AC-8.1]

**Approach:** `saleItem.findMany` + in-memory Map aggregation (NOT Prisma `groupBy`).

Rationale: `groupBy` with relation filters (`sale: { status: 'COMPLETED' }`) is not supported in Prisma for all DB providers. The in-memory approach is also simpler to unit-test with vi.hoisted() mocks.

```typescript
// src/features/analytics/services/analytics.service.ts
static async getSalesVelocity(lookbackDays = 28): Promise<SalesVelocityRecord[]> {
  const since = new Date(Date.now() - lookbackDays * 24 * 60 * 60 * 1000)
  const items = await prisma.saleItem.findMany({
    where: {
      sale: { status: 'COMPLETED' },
      createdAt: { gte: since },
    },
    include: {
      variant: { include: { product: true } },
    },
  })

  const map = new Map<string, { variant: typeof items[0]['variant']; unitsSold: number }>()
  for (const item of items) {
    const entry = map.get(item.variantId)
    if (entry) {
      entry.unitsSold += item.quantity
    } else {
      map.set(item.variantId, { variant: item.variant, unitsSold: item.quantity })
    }
  }

  const weeks = lookbackDays / 7
  return Array.from(map.values()).map(({ variant, unitsSold }) => ({
    variantId: variant.id,
    productName: variant.product.name,
    brand: variant.product.brand,
    sku: variant.sku,
    frameColor: variant.frameColor,
    lensColor: variant.lensColor,
    unitsSold,
    weeksCovered: weeks,
    unitsPerWeek: unitsSold / weeks,
  }))
}
```

**CRITICAL:** `lookbackDays / 7` uses float division — `28 / 7 = 4.0`, not integer division. Never use `Math.floor()` on the divisor.

### getCriticalStockouts — Zero-Velocity Guard

[Source: FR-8 AC-8.2, AC-8.3]

```typescript
const daysUntilStockout = unitsPerWeek > 0
  ? Math.floor((inv.quantity / unitsPerWeek) * 7)
  : null  // infinite — no sales in lookback window

const isCritical = daysUntilStockout !== null && daysUntilStockout < threshold
```

**`null` means infinite, NOT zero.** A variant with velocity=0 is NOT critical — it's dead stock (handled separately). The `getCriticalStockouts` filter should NOT include variants with `daysUntilStockout = null`.

### getDeadStock — Filter Pattern

[Source: FR-11 AC-11.3 — "variantes sem movimento nos últimos 60 dias"]

```typescript
const cutoff = new Date(Date.now() - daysSinceLastSale * 24 * 60 * 60 * 1000)
const variants = await prisma.productVariant.findMany({
  where: { product: { isArchived: false } },
  include: {
    product: true,
    inventory: true,
    saleItems: {
      where: {
        sale: { status: 'COMPLETED' },
        createdAt: { gte: cutoff },
      },
      select: { id: true },
    },
  },
})

return variants.filter((v) => v.saleItems.length === 0).map((v) => ({ ... }))
```

**Only COMPLETED sales count.** CANCELLED/RETURNED sales must not reset the dead stock timer.
